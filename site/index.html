How to add or fix a conference

Every conference is one small YAML file in data/conferences/. Pick whichever way is easiest for you.

  1. Fill in a form (no Git needed)

    Open the "Add a conference" form, fill in what you know and submit. A bot turns it into a pull request, and a maintainer merges it.

    Found a wrong or outdated date? Every conference has a Report outdated info button that opens a prefilled form.

  2. Edit the file on GitHub

    Open a conference in the table and press Edit on GitHub. GitHub opens the file in its editor; change it and choose "Propose changes". People without write access get a fork and a pull request automatically.

    New conference: create a new file from the template, rename it to <id>.yml and fill it in.

  3. Locally

    git clone https://github.com/OWNER/REPO.git
cp data/_template.yml data/conferences/myconf.yml   # edit it
pip install pyyaml
python3 scripts/build.py --serve                     # check at http://localhost:8000

What to write

  • tier: top flagship of its field, major well-established and competitive, minor smaller or regional, domestic national conference in a local language.
  • notes: short facts people need when choosing a venue, like the lab seminar slides: organizer, proceedings, where it is held, reputation, acceptance rate, fee, anything unusual.
  • editions: the latest edition and the next one when announced, with every submission deadline. Dates are YYYY-MM-DD; add time and tz (for example AoE) when the call for papers states them.
  • rank: CORE from the CORE portal (ICORE2026) and the CCF list (CCF 2026). Leave empty if not listed.
  • sources and last_verified: where you checked and when, so others know how fresh it is.

The full field guide is in CONTRIBUTING.md. When no confirmed date exists yet, the site estimates the next one from the previous edition and marks it with ~.
